Política de privacidad de shorts-bot

Última actualización: 20 de noviembre de 2026.

shorts-bot es una aplicación de uso personal. Solo la usa su propietario para gestionar su propio canal de YouTube.

Datos a los que accede

  • Permiso para subir vídeos al canal del propietario (YouTube Data API).
  • Lectura de las estadísticas y los datos públicos del propio canal (YouTube Data API y YouTube Analytics API).

Uso de los datos

Los datos se usan solo para publicar vídeos y analizar su rendimiento con el fin de mejorar el contenido. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

El uso de la información recibida de las APIs de Google cumple la Política de Datos de Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.

Almacenamiento y revocación

Las credenciales se guardan cifradas como secretos privados. Puedes revocar el acceso en cualquier momento desde myaccount.google.com/permissions.

Este servicio usa los Servicios de API de YouTube. Consulta las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.
